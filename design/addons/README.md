# Example addons

Each folder is an addon (see [../addons.md](../addons.md)). To try one, zip the
folder, or its contents, and install the .zip in Settings › Addons on the web.
To install `solarized` straight from GitHub, paste the address of its
`addon.json`; that brings only its colours, as a lone addon.json has no
other files:

    https://raw.githubusercontent.com/AlxndrJhn/anchor/main/design/addons/solarized/addon.json
